## [SCRIPT-01] Purpose
NCPDP SCRIPT is the US standard message format for exchanging prescription information between prescriber systems, pharmacies and payers.

## [SCRIPT-02] Transaction types
SCRIPT transactions include: new prescription, change request, cancel, refill/renewal, medication history and fill status.

## [SCRIPT-03] Mandated versions change over time
CMS mandates specific versions of SCRIPT, and the mandated version changes over time. A conforming system must therefore support upgrading to new SCRIPT versions.
